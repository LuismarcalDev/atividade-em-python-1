ATIVIDADES DE PYTHON: MÓDULOS E AMBIENTES VIRTUAIS

Atividade 1:
Abra a pasta atividade1 e execute:
python calculos.py

Atividade 2:
Abra a pasta atividade2 e execute:
python sorteio.py

Atividade 3:
Abra a pasta atividade3 e execute:
python principal.py

Atividades 4 e 5:
Abra a pasta projeto_ambiente.

Para usar o primeiro ambiente no PowerShell:
.\.venv\Scripts\Activate.ps1
python verificar_ambiente.py
python mensagem.py
deactivate

Para usar a cópia do ambiente no PowerShell:
.\.venv_copia\Scripts\Activate.ps1
python verificar_ambiente.py
python mensagem.py
deactivate
